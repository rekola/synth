# Chords of the otonal and utonal scales

The otonal scale (C D♯ E F G A A𝄰 = 1/1 7/6 5/4 4/3 3/2 5/3 7/4) is harmonics
12, 14, 15, 16, 18, 20 and 21 of the F below its tonic, so any notes taken from
it are a slice of one harmonic series: every chord in it is otonal. The utonal
scale (C E𝄫 E♭ F G A♭ B𝄫 = 1/1 8/7 6/5 4/3 3/2 8/5 12/7) is its mirror, undertones
of one high G, and every chord in it is utonal. The mirror turns each otonal
chord a:b:c into the utonal 1/c:1/b:1/a, upside down: a major triad becomes a
minor one, a subminor triad a supermajor one.

The table lists each chord type in root position: the notes stacked upward from
the lowest within one octave. The intervals are between neighbouring notes,
bottom to top. A proportion written with fractions is the same chord as
whole numbers given after it.

| Chord | Proportion | Intervals | Otonal | Utonal |
|---|---|---|---|---|
| Harmonic seventh | 4:5:6:7 | 5:4, 6:5, 7:6 | C E G A𝄰, F A C D♯ | |
| Half-diminished seventh | 1/7:1/6:1/5:1/4 (60:70:84:105) | 7:6, 6:5, 5:4 | | E𝄫 F A♭ C, B𝄫 C E♭ G |
| Major | 4:5:6 | 5:4, 6:5 | C E G, F A C | A♭ C E♭ |
| Minor | 10:12:15 | 6:5, 5:4 | A C E | C E♭ G, F A♭ C |
| Subminor | 6:7:9 | 7:6, 9:7 | C D♯ G | E𝄫 F B𝄫 |
| Supermajor | 14:18:21 | 9:7, 7:6 | D♯ G A𝄰 | F B𝄫 C |
| Diminished | 5:6:7 | 6:5, 7:6 | E G A𝄰, A C D♯ | |
| Diminished | 1/7:1/6:1/5 (30:35:42) | 7:6, 6:5 | | E𝄫 F A♭, B𝄫 C E♭ |
| Seventh, no fifth | 4:5:7 | 5:4, 7:5 | C E A𝄰, F A D♯ | |
| | 1/7:1/5:1/4 (20:28:35) | 7:5, 5:4 | | E𝄫 A♭ C, B𝄫 E♭ G |
| Seventh, no third | 4:6:7 | 3:2, 7:6 | C G A𝄰, F C D♯ | E𝄫 B𝄫 C |
| | 1/7:1/6:1/4 (12:14:21) | 7:6, 3:2 | C D♯ A𝄰 | E𝄫 F C, B𝄫 C G |
| Cluster | 6:7:8 | 7:6, 8:7 | C D♯ F, G A𝄰 C | B𝄫 C E𝄫 |
| Cluster | 1/8:1/7:1/6 (21:24:28) | 8:7, 7:6 | A𝄰 C D♯ | C E𝄫 F, G B𝄫 C |

The other three-note chords are inversions of these, or sets with wider
proportions. G A𝄰 D♯, for example, is 18:21:28: the supermajor triad on D♯
with G in the bass.

Some degrees carry no triad of their own. Above otonal's A𝄰 (7:4) the scale has
8:7, 4:3, 10:7, 32:21, 12:7 and 40:21: no third, and F is 27 cents wider than
a fifth. A chord with A𝄰 in the bass is an inversion, such as A𝄰 C E (7:8:10,
C E A𝄰 turned) or A𝄰 E G (7:10:12, E G A𝄰 turned), or the cluster A𝄰 C D♯:
A𝄰 is a seventh or a fifth in its chords, never their root. In the utonal
scale, E♭ has a 5:4 above it (G) but no fifth, so it carries no triad of the
table either.

Played live, recorded or typed, and after `apply-just-intonation-region`, each
note of either scale sounds at its exact ratio to the key, so these chords
come out pure ([user-interface.md](user-interface.md#just-intonation)).
Without a tuning correction, 31 and 53-EDO come within 6 cents of every ratio;
12 and 19-EDO only approximate the septimal ones.
