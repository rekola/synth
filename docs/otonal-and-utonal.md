# Chords of the otonal and utonal scales

The otonal scale (C D♯ E F G A A𝄰 = 1/1 7/6 5/4 4/3 3/2 5/3 7/4) is harmonics
12, 14, 15, 16, 18, 20 and 21 of the F below its tonic, so any notes taken from
it are a slice of one harmonic series: every chord in it is otonal. The utonal
scale (C E𝄫 E♭ F G A♭ B𝄫 = 1/1 8/7 6/5 4/3 3/2 8/5 12/7) is its mirror,
undertones of one high G, and every chord in it is utonal. The mirror turns
each otonal chord a:b:c into the utonal 1/c:1/b:1/a, upside down: a major
triad becomes a minor one, a subminor triad a supermajor one.

Chords are listed in root position: the notes stacked upward from the lowest
within one octave. Intervals are between neighbouring notes, bottom to top. A
proportion written with fractions is the same chord as the whole numbers after
it.

## Triads

A triad divides a consonant interval in two. The familiar ones divide the fifth
(3:2) into two thirds, but dividing the fourth (4:3) into a third and a second
is no less a choice. Here a triad that spans a fourth is called quartal (the
word usually means chords stacked in fourths). The two divisions match: 4:5:6
divides the fifth at its arithmetic mean and 10:12:15 at its harmonic mean, and
6:7:8 and 21:24:28 do the same for the fourth.

|---|---|---|---|---|---|
| Fifth | Major | 4:5:6 | 5:4, 6:5 | C E G, F A C | A♭ C E♭ |
| Fifth | Minor | 10:12:15 | 6:5, 5:4 | A C E | C E♭ G, F A♭ C |
| Fifth | Subminor | 6:7:9 | 7:6, 9:7 | C D♯ G | E𝄫 F B𝄫 |
| Fifth | Supermajor | 14:18:21 | 9:7, 7:6 | D♯ G A𝄰 | F B𝄫 C |
| Fourth | Quartal | 6:7:8 | 7:6, 8:7 | C D♯ F, G A𝄰 C | B𝄫 C E𝄫 |
| Fourth | Quartal | 1/8:1/7:1/6 (21:24:28) | 8:7, 7:6 | A𝄰 C D♯ | C E𝄫 F, G B𝄫 C |
| Fourth | Quartal | 15:18:20 | 6:5, 10:9 | E G A | C E♭ F |
| Fourth | Quartal | 9:10:12 | 10:9, 6:5 | G A C | E♭ F A♭ |

| Fourth | Quartal | 15:16:20 | 16:15, 5:4 | E F A | G A♭ C |

Every degree of both scales is the root of a triad of one span or the other.
Some have no fifth above them and carry only quartal triads: otonal E, G and
A𝄰, utonal E♭, G and B𝄫. A𝄰's is 21:24:28; above it the scale has no third,
and F is 27 cents wider than a fifth. Others have no fourth above them and
carry only fifth-span triads: otonal D♯, F and A, utonal E𝄫, F and A♭.

| Otonal | Fifth | Fourth | | Utonal | Fifth | Fourth |
|---|---|---|---|---|---|---|
| C | C E G, C D♯ G | C D♯ F, C E F | | C | C E♭ G | C E𝄫 F, C E♭ F |
| D♯ | D♯ G A𝄰 | | | E𝄫 | E𝄫 F B𝄫 | |
| E | | E G A, E F A | | E♭ | | E♭ F A♭, E♭ G A♭ |
| F | F A C | | | F | F A♭ C, F B𝄫 C | |
| G | | G A𝄰 C, G A C | | G | | G B𝄫 C, G A♭ C |
| A | A C E | | | A♭ | A♭ C E♭ | |
| A𝄰 | | A𝄰 C D♯ | | B𝄫 | | B𝄫 C E𝄫 |

The other three-note chords are inversions of these, or sets with wider
proportions. G A𝄰 D♯, for example, is 18:21:28: the supermajor triad on D♯
with G in the bass.

## Tuning

Played live, recorded or typed, and after `apply-just-intonation-region`, each
note of either scale sounds at its exact ratio to the key, so these chords
come out pure ([user-interface.md](user-interface.md#just-intonation)).
Without a tuning correction, 31 and 53-EDO come within 6 cents of every ratio;
12 and 19-EDO only approximate the septimal ones.
